## Skill: debug-first

Kanus-a gamiton: kung naay error, bug, o wala damha nga behavior.

- **I-reproduce una** ang error sa dili pa mo-ayo — kung dili nimo makita, dili nimo maayo.
- Basaha ang **tibuok** error message ug stack trace — ang tubag kasagaran naa diha.
- Ayaw pagtag-an og ayo: dugangi og logs o gamay nga test para makita ang tinuod nga kahimtang.
- Ayoha ang **hinungdan**, dili ang sintomas — ayaw taboni og try/catch nga hilom.
- I-verify human: dagana pag-usab ang reproduction ug siguroha nga nawala ang error.
